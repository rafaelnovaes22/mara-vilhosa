# Constitution — Mara Vilhosa (Foundry lite)

1. C1 Diagnose antes do design: cardápio e operação reais do Instagram/iFood antes de código.
2. C2 Outcome primeiro: pedido certo (retirada com código ou plataforma) — nunca tech primeiro.
3. C3 Custo ≤25%: assistente local sem LLM; site estático single-file, sem backend.
4. C4 SHADOW antes de cobrar: IA só indica; humano confirma no zap.
5. C5 Contexto em 3 níveis: loja (endereço/horário), pedido (itens/total), cliente (retirada/entrega).
6. C6 Telemetria: log de pedido no zap + contagem de cliques (sem PII).
7. C7 Portabilidade: HTML puro, sem lock-in; links iFood/WhatsMenu externos.
8. C8 Sem customização heroica: só 2 fluxos — retirada e plataforma.
